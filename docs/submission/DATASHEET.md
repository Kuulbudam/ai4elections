# Datasheet: data used by Election as a System (EaaS)

Three datasets are used. None contains personal data.

| | EaaS synthetic results | Rise starter data (copy) | CCIJ/VEZA 2023 Plateau |
|---|---|---|---|
| **1. Motivation** | Test every rule and statistical case with a known answer | Score EaaS against the organisers' answer key | Check speed and behaviour on real public data |
| **2. Composition** | 12,023 fictional polling units in 3 fictional states; 15 planted scenarios (bad cells, impossible figures, duplicates, unusual turnout/share, small and zero-spread wards); ground truth per row | 900 fictional units, parties A–E; 42 planted anomalies of 5 types; answer key | 4,989 real polling units, 2023 presidential results as transcribed from EC8A sheets |
| Synthetic / public / authorised | Synthetic | Synthetic | Public |
| Personal or sensitive data | No | No | No (aggregate counts only) |
| **3. Collection** | `tools/synthetic/generate.py`, seed 2026, deterministic | Organisers' generator; copied from their repo at commit 47ea94a | Downloaded from CCIJ/VEZA's public repository at run time by `tools/real_data/prepare_ccij.py` |
| **4. Preprocessing** | None | None (valid votes = sum of party votes, as the file has no separate column) | Column renaming; partial party list flagged; nothing altered |
| **5. Uses** | Tests, demos | Evaluation only | Live checks and demo; not for conclusions about the 2023 election |
| Must not be used for | Conclusions about any real election | Same | Accusations; anything beyond checking figures against sheets |
| **6. Distribution** | In repo, `data/synthetic/`, MIT | In repo, `data/rise-starter/`, CC BY 4.0 © Rise Networks | Not redistributed; fetched at run time |
| **7. Maintenance** | Regenerated by the script; a test fails if the committed files drift | Re-copy if organisers update | Re-downloaded each run |
| **8. Limits and biases** | Simple distributions; small-number artefacts (3 normal units repeat another's scores by chance) | Random figures, so statistical outliers are not planted; wards of 5 units | Transcription errors; 1,016 units with blank or unreadable sheets |

SHA-256 of each file is recorded when it is uploaded to EaaS and shown on every report.
